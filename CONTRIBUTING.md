# Contributing Guidelines

Thank you for your interest in contributing! We have strict requirements for our contributors. Please read the following rules and processes carefully before you begin.

## How to Become a Contributor

To officially become a contributor, you must complete the following steps:

1. **Resolve Bugs:** Successfully fix **3 or more** active issues that are labeled as bugs.
2. **Contact:** Once you have completed the fixes, send an email to **mehrad75oo@gmail.com** stating, *"I did it."*
3. **Skill Check:** You will be evaluated to verify that you know how to code in **Java and/or Kotlin**. 

## Contributor Rules & Restrictions

If you are accepted as a contributor, you must strictly follow these rules at all times:

* **Human Code Only (NO AI):** You CANNOT use any AI agents, code generators, or AI assistants on this code. Only 100% human-written code is accepted.
* **Limited Scope:** Contributors are only allowed to **fix bugs** and **help people on issues**. 
* **Pre-Commit Review:** Before you commit any changes, you must contact me directly and provide the source code for review.
* **Zero Tolerance for Malicious Code:** Adding anything harmful or "bad" will result in an immediate kick from the contributors team.

## The April Fools Version

Every April, we create a special April Fools version built completely from scratch. 
* Only specific Mods and select Contributors are granted permission to make changes to this version. 

## Discord and Staff Requirements

Communication and role assignments happen on our Staff Discord Server. 

* **Joining is Mandatory:** You must be on our Staff Discord Server to get your Contributor role.
* **Getting the Invite:** To get the Discord server link, you must email me and already be verified as Staff.
* **Failure to Join:** If you are selected as Staff and a Contributor but do not join the Discord server, you will be **banned from being a contributor FOREVER.**
