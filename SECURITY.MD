# Security Policy and Bug Reporting

Thank you for helping us keep this Minecraft plugin safe, stable, and fun for everyone! Please read the guidelines below to learn how to report bugs, request help, or report security vulnerabilities.

## 🐛 Found a Bug?
If you found a bug, glitch, or unexpected behavior in this Minecraft plugin, please do not hesitate to let us know! 

* **Where to report:** Please open a detailed report on our [Issue Tracker](../../issues).
* **Response Time:** A member of our team will review your report and respond within **24 to 72 hours**.

### What to include in your bug report:
To help us fix the issue quickly, please include:
1. **Plugin Version:** The exact version of the plugin you are running (e.g., v1.4.2).
2. **Server Software:** The server jar and version you are using (e.g., Paper 1.20.4, Purpur, Spigot).
3. **Error Logs:** Copy and paste any relevant console errors or stack traces (we highly recommend using [Pastebin](https://pastebin.com) or [Mclo.gs](https://mclo.gs)).
4. **Steps to Reproduce:** A short list of steps showing exactly how to trigger the bug.

---

## 🛡️ Reporting a Security Vulnerability
If you discover a critical security vulnerability (such as an exploit that allows unauthorized admin access, a dupe glitch, or a server crash exploit), **please do not open a public issue.** 

Instead, please report security vulnerabilities privately to keep the community safe while we work on a fix.

### How to report privately:
* **GitHub Private Vulnerability Reporting:** If enabled, please use the "Report a vulnerability" button under the **Security** tab of this repository.
* **Alternative Contact:** [mehrad75oo@gmail.com]

We take security issues very seriously and will prioritize a patch immediately.

We actively support and patch the latest releases of the plugin. Older legacy versions may not receive regular updates.

| Previous Releases | 🔄 Only for critical security patches |
